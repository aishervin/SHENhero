opencode web UI for Termux

Run the real opencode web UI locally on Android, with editable source and your own opencode server.

Install

curl -fsSL https://raw.githubusercontent.com/aishervin/SHENhero/main/termux-skin/install.sh | bash

The installer downloads the proxy, launchers and prebuilt UI, starts a local opencode serve process with a random password, and opens 127.0.0.1 in your browser.

Commands

opencode-web-open
opencode-web-stop
opencode-web-update

Edit the UI

The original UI source is vendored under ui-src/. Clone the repository, edit ui-src/packages/..., then build: 

git clone https://github.com/aishervin/SHENhero
cd SHENhero/termux-skin
./ui-src/build.sh
OC_UI_DIR="$PWD/ui" opencode-web-open

The build targets opencode v1.19.4, overlays the vendored source onto the matching upstream tag, and builds packages/app.
